## How to Use Genres in Suno

When crafting the **Style of Music** field in Suno Custom Mode:

1. **Primary Genre**: Start with the main genre (e.g., "indie rock", "lo-fi hip hop")
2. **Style Modifiers**: Add descriptive styles (e.g., "dreamy", "aggressive", "melodic")
3. **Era/Influence**: Optionally add decade or regional flavor (e.g., "80s", "japanese")
4. **Combine Thoughtfully**: Suno handles genre-blending well (e.g., "folk metal", "electro swing")

**Example Style Field:**
```
dreamy indie pop, ethereal, female vocalist, 90s influenced, 95 BPM
```

### Section Markers

### Vocal Tags
[Male Vocal], [Female Vocal], [Female Narrator], [Duet], [Choir], [Gospel Choir], [Diva Solo], [Primal Scream], [Shout], [Rap Verse], [Rapped Verse]

### Mood Tags
[Melancholy], [Whimsical], [Soft Intro], [Happy Chorus], [Sad Verse], [Emotional Bridge], [Catchy Hook], [Hook], [Refrain]

### Endings
[Outro], [End], [Fade Out], [Fade Out and End], [Fade to End], [Finale]

### Pro Tip
