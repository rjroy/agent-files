Compress a conversation or thought thread into portable signal without losing what shifted.

Accept the prior exchange or thought thread (or use current conversation if not specified).

Extract and preserve:
1. **Root question**: What was this actually about?
2. **Key shifts**: What changed in framing, assumptions, or understanding?
3. **Revealed assumptions**: What was discovered to be assumed?
4. **Emergent tensions**: What contradictions surfaced?
5. **Insights worth keeping**: What deserves to persist?
6. **Next turn**: What prompt or approach should follow?

Output format:
```
## Thread Reference
Root Question: [...]

## Engagement Log
[Date] — [Lens/Mode used]
Prompt/Method: [...]

### Key Shifts & Surfaces
**Framing Change**: From [old frame] → to [new frame]
**Revealed Assumption**: [...]
**Emergent Tension**: [...]
**Insight Worth Keeping**: [...]

### Next Turn
[Prompt or approach that would extend this thinking]
```

This creates a reusable artifact for future inquiry or to return to the thread later.
