# Inquiry digest

Use the prior exchange or thought thread the user identifies, or the current conversation when that is clearly the intended target. If the target is ambiguous, ask which material to digest. Do not invent dates, lenses, or modes; mark unavailable details as unspecified or omit them.

Preserve:
1. The root question: what the discussion was actually about.
2. Key shifts in framing, assumptions, or understanding.
3. Revealed assumptions.
4. Emergent tensions or contradictions.
5. Insights worth keeping.
6. A useful prompt or approach for the next turn.

Return a concise, reusable Markdown digest with a thread reference, an engagement log when details are known, key shifts and surfaces, and a next-turn section. Present it in the conversation; save it to a file only when the user asks or specifies a destination.
