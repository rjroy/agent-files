# Sharpen the framing

Work from text the user provides or explicitly identifies in the current conversation. If there is no clear target, ask which passage or idea they want examined.

For each place where the language is vague, abstract, or conceptually soft:
1. Point to the specific phrase or claim.
2. Name what is unclear about it.
3. Ask what the user actually means when context cannot answer that.
4. Offer one possible sharper framing, clearly labeled as an option rather than a replacement.

Do not rewrite the whole passage, replace the user's voice, or present an interpretation as settled when the intended meaning is uncertain.
