# Convergence Move 🪢

A skill for moving forward when thinking is stretched but nothing fully resolves—and you still need to act.

---

## Use This When

- You've stretched the thinking, but nothing fully resolves
- You need to move without faking alignment
- Multiple viable paths exist and tension is real
- You can't hold the open loop anymore but won't force false clarity

---

## What This Does

Convergence Move helps you act with judgment when full resolution isn't possible:

1. Scans for structural tensions in the current exploration
2. Assesses whether movement is possible or premature
3. Provides conditional output based on what's actually present:
   - **Paths forward** when grounded in actual tensions
   - **Reality check** if movement would sacrifice necessary thinking
   - **Name the contradiction** if the tension itself is the answer

---

## Operation Flow

### Step 1: Scan for Structural Tensions
What contradictions, trade-offs, or unresolved questions are live?

### Step 2: Assess Movement Readiness
Three possible states:
- **Ready to move**: Tensions are clear enough to act with
- **Premature**: More exploration needed before movement makes sense
- **Tension IS the answer**: The contradiction should be held, not resolved

### Step 3: Conditional Output
Based on assessment, provide:

**Option A: Convergence Paths** (when movement is grounded)
- What paths forward exist
- What each path holds/releases
- What judgment each requires

**Option B: Movement Reality Check** (when premature)
- Why movement would be premature
- What's still needed before acting
- Where to focus next

**Option C: Tension-as-Solution** (when contradiction is the point)
- Why this tension should be held
- What the contradiction is protecting
- How to communicate the held tension

---

## Output Format

```
### Structural Tensions
[What contradictions or trade-offs are active]

### Judgment Pressure
[What's pushing for movement]

### Held Contradictions
[What can't and shouldn't resolve]

### [Convergence Paths | Movement Reality Check | Tension-as-Solution]

[Conditional output based on assessment]
```

- [Where to focus]
- [What mode would help]

---

## Flows Into

- **Writing Workshop** → turn the convergence frame into public-facing clarity
- **Simulated Debate** → if tension demands deeper surfacing before integration
- **Coherence Pass** → if signal still feels unstructured (and structure is honest)
- **Inquiry Digest** → if it needs to be packaged for later analysis
- **Exploratory Reasoning** → if contradiction reveals need for different thinking approaches

---

## Guards

- **Don't force convergence**: Better to say "not yet" than fake alignment
- **Respect real contradictions**: Some tensions are features, not bugs
- **Multiple paths are valid**: Not every decision has one right answer
- **Movement has cost**: Be explicit about what each path releases

---

## Example Invocation

"Run Convergence Move - I've been circling this decision and need to figure out if I can act."

"Convergence mode - we've explored multiple approaches and I need to see if any path is grounded enough."

"I think we need to move but I'm worried we're forcing it. Help me check."
