# Trim a draft

Accept draft text supplied in the conversation. If no draft is present, ask the user to paste or identify it; do not invent one or silently choose unrelated prior text.

Identify roughly 10–15% to cut, prioritizing:
- Hedging that weakens a claim
- Redundant explanations
- Scaffolding that does not carry weight
- Politeness that obscures directness

Mark the proposed deletions in place or quote each proposed cut, then explain how it strengthens what remains. Do not rewrite or silently apply the cuts. If the material does not support a useful 10–15% reduction, say so rather than padding the list.
