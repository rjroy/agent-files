# Coherence Pass 🪢

A skill for finding patterns in rich notes without forcing structure that isn't there.

---

## Use This When

- You have rich notes but no throughline
- You see sharp insights but no structure
- You suspect patterns but can't name them
- You want to integrate without manufacturing coherence

---

## What This Does

Coherence Pass reviews your thinking to find genuine patterns—or honestly acknowledges when coherence would be forced:

1. Reviews context (thread, notes, session, document)
2. **Reality checks** whether coherence actually exists
3. If patterns exist → clusters and integrates them
4. If not → acknowledges fragmentation and suggests productive next moves

---

## Operation Flow

### Step 1: Review Context
Examine the material you provide: notes, conversation threads, draft documents, exploration logs.

### Step 2: Reality Check
**Key question**: Does coherence genuinely exist, or would claiming it be forced?

Two honest outcomes:
- **Coherence exists**: Real patterns can be named without manufacturing them
- **Coherence forced**: Structure would be artificial; fragmentation is the truth

### Step 3: Conditional Output

**Path A: Coherence Exists**
- Exploration summary
- Insight clusters
- Integration paths
- Judgment prompts testing the patterns

**Path B: Coherence Forced**
- What was found (honestly)
- What's missing
- Why integration would be premature
- Productive next moves instead

---

## Output Format

### Option A: Coherence Exists

```
### Exploration Summary
[Themes and pivots across the material]

### Insight Clusters

**Cluster 1: [Theme]**
- [Related insight]
- [Another related insight]
- [Connection across them]

**Cluster 2: [Theme]**
- [...]

### Integration Paths
How these clusters relate or build on each other.

### Judgment Prompts
[Questions that test whether the patterns hold]
```

### Option B: Coherence Forced

```
### Integration Reality Check

**What I Found:**
[Honest assessment of what's actually there]

**What's Missing:**
[Gaps that prevent clean integration]

**Why Forcing Structure Would Fail:**
[What it would obscure or manufacture]

**Productive Next Moves:**
- [Alternative approach]
- [What mode might help]
- [What exploration is still needed]
```

---

## Anti-Hallucination Guards

**This skill will never:**
- Claim patterns that aren't genuinely there
- Group insights just because they use similar words
- Manufacture throughlines to satisfy the request

**It commits to:**
- Verify patterns before claiming them
- Only group insights that genuinely relate
- Name gaps honestly when coherence doesn't exist
- Offer alternatives when integration would be forced

---

## Flows Into

- **Writing Workshop** → to compress insight into guidance language
- **Inquiry Digest** → to capture distilled version post-integration
- **Exploratory Reasoning** → if fragmentation suggests need for different thinking approaches
- **Convergence Move** → once patterns are clear enough to act on
