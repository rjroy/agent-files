# Judgment primer

Use the user's supplied reflection, document, topic, or the current conversation when clearly requested. If the target is unclear, ask what context to examine.

First check whether real judgment pressure exists. If it does, return exactly three concise questions tied respectively to actual stakes, a plausible blind spot, and purpose or values. Ground each in the material and name the specific pressure point that produced them.

If no genuine pressure is present, do not generate questions just to fill the format. Say that the current state appears clear, identify what is missing if anything, and offer useful next moves such as proceeding, specifying a concern, or using Exploratory Reasoning to examine distinct paths.
