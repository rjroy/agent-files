# Remove Background Models

Models available for background removal.

## Models

| Model ID | Vendor | Cost/Image | Output Format |
|----------|--------|-----------|---------------|
| `bria/remove-background` | Bria AI | $0.01 | PNG (transparent) |

## Notes

- `bria/remove-background` uses RMBG 2.0 and always outputs a transparent PNG.
- Output file extension is auto-corrected to `.png` regardless of the input format.
